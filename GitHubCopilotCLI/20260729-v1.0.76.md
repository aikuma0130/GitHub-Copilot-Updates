# GitHub Copilot CLI v1.0.76 - 2026-07-29 アップデート情報

## リリース日

2026-07-29

## GitHub Copilot CLI バージョン

1.0.76

## 概要

プラグイン・MCP サーバー等の有効化/無効化コントロールの追加、grok-4.5 モデルのサポート、セッションサイドバーやキューマネージャーなど多数の新機能が追加されました。エンタープライズ向けサンドボックスポリシーの管理設定機能も導入されています。

## 変更点

### 新機能
- /plugins にプラグイン、インストラクション、エージェント、LSP サーバー、フックの有効化/無効化コントロールを追加
- grok-4.5 モデルのサポートを追加
- 指示可能なキューマネージャー（staff）を追加し、キューに入ったメッセージの並び替え、編集、削除、再送、即時送信が可能に
- 複数セッションを管理するための新しい Sessions サイドバーを追加（`/experimental on` で有効化）
- エンタープライズ管理者がサンドボックスの制限フロアを強制可能に（管理設定はユーザーのポリシーを厳格化するのみで緩和はしない）
- ボイスモードで録音前にメディア再生を一時停止し、録音後に再開（macOS および Windows）
- フッターにアクティブなスケジュールプロンプトの数を表示
- /limits predict を追加し、類似セッションからセッションの AI クレジット制限を提案
- カスタムステータスラインコマンドの設定可能な定時リフレッシュを追加

### 改善
- macOS と Linux でサンドボックスの拒否パスが相対パスとシンボリックリンクに対して強制されるように（Windows ではパス単位の拒否不可）
- アップデートの自動ダウンロード時に /restart を提案し、警告色を非表示に
- /diff で大規模な複数ファイルの差分のスクロールとシンタックスハイライトが高速化
- Split-view サイドバー: ホバーでフォーカスがデフォルトで無効に（`sidebar.hoverFocus` でオプトイン）、アクティブセッションカードがデフォルトでアクセント表示
- `web_fetch` が HTTP リダイレクトに対応（異なるオリジンへのリダイレクト時は許可を求める）
- サンドボックス検索で即時バイパスプロンプトを提供し、重複するバイパスプロンプトを回避
- `web_fetch` がサンドボックスプロキシ経由でルーティングされるように（`network.allowOutbound` が false の場合はエグレスを拒否）
- サブエージェントの委任を小規模タスクと並列作業で改善
- ターン中の /model 変更をキューに入れ、現在の応答完了後に適用
- MCP ツールが定義スコープのスナップショットから高速にロードされるように（プロセス全体およびサーバー単位のキャッシュオプトアウト付き）
- autopilot が task_complete 後もデフォルトで選択状態を維持（`stayInAutopilot` を false に設定でインタラクティブモードに戻る）

### バグ修正
- 未送信のプロンプトテキストが入力されたセッションに留まるように修正（セッション切り替え時に追従しなくなった）
- セッション再開時にオートパイロットまたはプランモードが復元されるように修正
- URL 許可プロンプトがサンドボックスバイパスの警告とモデルの理由を保持するように修正
- サブエージェント完了後に「Holder terminated during creation」でセッションが毎ターン失敗する問題を修正
- スタートアップのヒントが Copilot インストラクションが存在しないリポジトリでのみ /init を提案するように修正
- `userPromptSubmitted` フックが非文字列値を返した場合にセッションが破損する問題を修正（フック出力は 10 MiB に制限）
- 大きなコマンドがファイルに書き込む際に最近のシェル出力を表示
- /instructions ピッカーが --no-custom-instructions を尊重するように修正
- Rio ターミナルで Kitty グラフィクスをサポートするインライン画像のレンダリング
- キューメッセージリストで空行や水増しカウントが表示される問題を修正（Ctrl+C で最新のキューメッセージを削除可能に）
- セッション中に `mouse` 設定を変更すると即座に反映されるように修正
- 回収不能なシステムおよびツールコンテキストが制限に近づいた際の早期警告を復元
- `/worktree` 切り替え後にセッションの作業ディレクトリが元のチェックアウトに戻る問題を修正
