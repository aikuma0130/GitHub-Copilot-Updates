# GitHub Copilot CLI v1.0.77 - 2026-07-30 アップデート情報

## リリース日

2026-07-30

## GitHub Copilot CLI バージョン

1.0.77

## 概要

ブラウザベースの OAuth ログインフローが追加され、ローカルターミナルでのデフォルトログイン方法となりました。また、macOS/Windows のネイティブ MDM 設定によるサンドボックスポリシーの強制が可能になりました。

## 変更点

### 新機能
- ブラウザベース（Web）の OAuth ログインフローを追加。ローカルインタラクティブターミナルでは `copilot login` のデフォルトに（リモート/ヘッドレスターミナルではデバイスコードがデフォルト）。`--web-flow`/`--device-code` でモードを強制可能
- macOS および Windows のネイティブ MDM 設定によるマネージドサンドボックスポリシーの強制をサポート
- Ctrl+G でエディタを開いて ask_user のフリーフォーム回答をプロンプトを閉じずに編集可能に

### 改善
- 無条件のオートパイロット承認時にバイパスが許可されている場合、現在のセッションのサンドボックスを無効化
- reasoning effort を省略してサーバーがデフォルトを選択できるように対応
