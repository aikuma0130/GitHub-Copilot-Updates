# GitHub Copilot CLI v1.0.78 - 2026-08-03 アップデート情報

## リリース日

2026-08-03

## GitHub Copilot CLI バージョン

1.0.78

## 概要

ツール呼び出しの所要時間表示、セッション再開の大幅な高速化、サンドボックス管理の改善、`/rewind` コマンドの Git 非依存化など、多数の機能追加・改善が含まれるリリース。

## 変更点

### 新機能
- タイムラインヘッダーにツール呼び出しの所要時間をリアルタイム表示（5秒以上の呼び出しが対象、`/settings showToolDurations` で無効化可能）
- 実験的な `/new-worktree` コマンドを追加（新しい worktree を作成し、その中で新しい会話を開始）
- `/permissions` コマンドを追加（承認モードの切り替え）
- ACP モードで `closeSession` リクエストによるセッション終了をサポート
- ACP プロンプト結果とライブ `usage_update` 通知でトークン使用量を公開
- `forceRemoteSettingsRefresh` マネージド設定を追加（起動時にマネージド設定の強制取得を要求）

### 改善
- ファーストパーティプラグインがセッション開始時に自動的に最新バージョンに更新
- インタラクティブシェルショートカットが Enter で起動し、「$」がアーム状態のときにインラインヒントを表示
- ローカルデスクトップの TTY なしサブプロセス（IDE 統合含む）では Copilot ログインがブラウザフローをデフォルトに変更（リモート/ヘッドレス環境はデバイスコードを継続）
- Split-view サイドバーの閉じる確認表示を `x again to close`（最後のセッションでは `x again to exit CLI`）に変更
- サンドボックスバイパスプロンプトからの無効化がそのセッションのみに適用され、新しいセッションはサンドボックス有効で開始
- マネージド設定のフェッチ失敗時にキャッシュへフォールバックし、キャッシュもない場合は fail-open で起動
- サンドボックスがシェルコマンドをブロックしバイパスが許可されている場合、モデルに問い合わせずにサンドボックス外での再実行を提案
- `/rewind` が Git 不要になり、Copilot が変更したファイルのみを復元（内容が最後の書き込みと一致しないファイルはスキップ）
- 新しいサンドボックス設定 `allowDevToolCaches`（デフォルト有効）により、サンドボックド環境でビルドツールのキャッシュ・レジストリ・インストールへのアクセスを許可
- GitHub MCP toolset/tool の明示的設定を尊重（gh CLI へのステアリングを停止）
- settings.json の不明なトップレベルキーに対して起動時に警告を表示
- `--model` のシェル補完で `auto` およびサポートされるモデル名を提案
- 長いセッショントランスクリプトをプログレッシブにレンダリングしスクロールの応答性を維持
- 長いセッションの再開が大幅に高速化・省メモリ化（230MB/74kイベントのトランスクリプトが約10秒から1秒未満に短縮、ピークメモリ約1/4）

### 削除
- `/allow-all` の自動セーフティジャッジモデルがユーザー設定不可に変更（ジャッジモデルは自動選択）

### バグ修正
- 拡張スラッシュコマンドが複数の拡張がロードされている場合にハンドラーを1回だけ実行するよう修正
- インライン画像がタイムラインスクロール後に最初の行が画像全体に繰り返されるバグを修正
- stdin からパイプされたプロンプトの `sessionEnd` フックが `-p` と同じ動作に修正
- Ctrl+Q がパーシャルトークンではなくハイライトされたスキル補完をエンキューするよう修正
- セッション切り替え時に MCP サーバーの再起動やフック状態の再構築が発生しなくなり、stale-hook エラーを防止
- OAuth 認証後に遅延 MCP ツールをリフレッシュ
