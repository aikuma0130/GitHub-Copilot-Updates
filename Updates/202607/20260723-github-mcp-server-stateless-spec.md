# GitHub MCP Server が次期 MCP 仕様（ステートレス）に対応

## 日付

2026-07-23

## ステータス

GA

## 概要

GitHub MCP Server が次期 MCP 仕様のステートレスプロトコルに対応。セッションと初期化ハンドシェイクが廃止され、スケーラビリティとクライアント接続の簡素化を実現。

## 詳細

### ステートレスプロトコルの主な変更点

- セッションと `initialize` ハンドシェイクの廃止
- プロトコルバージョン、クライアント情報、ケイパビリティは各リクエストの `_meta` フィールドで送信
- サーバーは `server/discover` エンドポイントでケイパビリティを公開
- スティッキーセッションや共有セッションストアが不要に

### アーキテクチャ上のメリット

- MCP デプロイのスケーリングが容易に
- クライアントの並列ハンドシェイクにより接続セットアップのレイテンシを削減
- Redis セッションの廃止によりリクエスト処理が高速化
- ログとシークレットスキャンが HTTP ヘッダーベースに変更（ディープパケットインスペクション不要）

### 拡張機能フレームワーク

- オプション機能は「拡張機能（Extensions）」として提供
- MCP Apps やエンタープライズ管理認証が拡張機能として実装
- タスクと MCP Apps がモジュール化
- 認可は OAuth/OpenID Connect ベストプラクティスに準拠

### 互換性と移行

- 公式 Tier 1 SDK は後方互換性を維持しつつ新プロトコルをベータサポート
- 公式 SDK 利用者はユーザーアクションが不要
- カスタム実装はおよそ1年以内に移行が必要
