# Claude Opus 5 が GitHub Copilot で利用可能に

## 日付

2026-07-24

## ステータス

GA

## 概要

Anthropic の最新モデル Claude Opus 5 が GitHub Copilot で利用可能に。複雑で長時間にわたるコーディングタスクにおいて、慎重な推論、効果的なツール使用、複数ステップにわたる信頼性の高い実行を提供。

## 詳細

### 主な特徴

- **エージェント型コーディングワークフローに最適化**: 自律的なコード変更、リグレッション検証、複数ツールの連携を要するタスクで高い性能を発揮
- **精密な変更と自己検証**: 的を絞った変更を行い、自身の作業を検証し、複雑なタスクでの不要な実行オーバーヘッドを削減
- **高リスクサイバーコンテンツに対する強化されたセーフガード**: サイバー関連やセキュリティ隣接のリクエストがブロックされる場合あり。その場合は追加の文脈を付けて言い換えるか、別のモデルを選択

### 対応プラン

- Copilot Pro+
- Copilot Max
- Copilot Business
- Copilot Enterprise

### 利用可能なサーフェス

- Visual Studio Code
- Visual Studio
- Copilot CLI
- GitHub Copilot クラウドエージェント
- GitHub Copilot アプリ
- github.com
- GitHub Mobile（iOS / Android）
- JetBrains
- Xcode
- Eclipse

### 課金

プロバイダー API リスト価格に基づく使用量ベース課金。

### 有効化

Copilot Enterprise および Business プランの管理者は、Copilot 設定で Claude Opus 5 ポリシーを有効化する必要あり。
