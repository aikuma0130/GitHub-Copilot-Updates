# Grok 4.5 が GitHub Copilot で利用可能に

## 日付

2026-07-28

## ステータス

GA

## 概要

xAI の最新推論モデル Grok 4.5 が GitHub Copilot で利用可能に。高速なエージェント型コーディングと複雑なマルチステップワークフローに特化し、大規模なコンテキストウィンドウを活用したコードベース全体の推論が可能。

## 詳細

### モデル特性

- 高速かつ高度な推論能力を持つエージェント型コーディングに最適化
- 非常に大きなコンテキストウィンドウにより、大規模なコードベースやマルチファイルの推論に対応
- エラー回復と安全なエージェント駆動型コード自動化に注力
- エンタープライズコーディング、研究、データサイエンスのタスクに適する

### 利用方法

- Copilot のモデルピッカーから Grok 4.5 を選択可能
- VS Code、Copilot CLI、Web、その他のサポート環境で利用可能
- チームおよびビジネスユーザーは管理者が Copilot 管理設定からモデルを有効化する必要がある場合あり

### 料金

- 入力トークン: $2 / 100万トークン
- 出力トークン: $6 / 100万トークン
- 低レイテンシ用途向けの高速バリアントも利用可能
