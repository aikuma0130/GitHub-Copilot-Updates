# GitHub Copilot in Visual Studio — 2026年7月アップデート

## 日付

2026-07-30

## ステータス

GA / Public Preview

## 概要

Visual Studio 2026 に Copilot SDK ベースの新エージェント、.NET/Azure チームによるビルトインスキル、選択コードレビュー機能、組織レベルのカスタム指示が追加された。

## 詳細

### ハイライト

- **新エージェント（パブリックプレビュー）**: Copilot SDK をベースとした新しい **Agent (Preview)** オプションがエージェントピッカーに追加。より少ないやり取りで正確なタスク完了を実現し、レスポンスも短く読みやすくなった。
- **ビルトイン .NET / Azure スキル**: .NET チームと Azure チームのエキスパートが作成したビルトインスキルが追加。ツールピッカーの「Built-in」カテゴリから有効化可能。デフォルトはオフ。
- **選択コードのレビュー**: エディターでコードを選択し、右クリック → **Copilot Actions** → **Review Selection** でインラインコメントを取得。GitHub Copilot Code Review による提案の適用も可能。
- **組織レベルのカスタム指示**: GitHub 組織オーナーが組織全体に適用されるカスタム指示を追加可能に。開発者ごとの設定が不要になり、組織のリポジトリで自動適用。Copilot Business / Enterprise が必要。

### 利用可能プラン

- 組織レベルのカスタム指示は Copilot Business / Enterprise が必要。
- 新エージェント、ビルトインスキル、選択コードレビューは全プランで利用可能。
