# GitHub Copilot in VS Code — 2026年7月リリースまとめ

## 日付

2026-07-30

## ステータス

GA / Public Preview

## 概要

VS Code v1.127〜v1.131 の Copilot アップデート。エージェントウィンドウの再設計、マルチチャットセッション、Copilot Vision GA、ディクテーション機能など多数の機能強化を含む。

## 詳細

### エージェントウィンドウの改善（パブリックプレビュー）

- **コードとチャットの並列表示**: エディターパネルが再設計され、ファイルやdiffを会話の横で開ける。
- **高速レビューワークフロー**: ファイルごとの追加・削除行数表示、コンパクトdiffビュー、インラインとサイドバイサイドの切り替え。
- **Worktree 対応**: Copilot、Claude、Codex セッションを Git worktree で開始し、セッションごとにリポジトリの分離コピーで作業可能。
- **クイックチャット**: ワークスペースを開かずに質問可能。
- **セッションのグループ化と並べ替え**: ドラッグ&ドロップでの操作に対応。
- **サブエージェントの追跡**: 各サブエージェントのモデル、経過時間、アクティブなツール呼び出しを表示。
- **PR 更新のチャット内処理**: 失敗した CI チェックやレビューコメントにチャット入力上のバナーから対応。

### マルチチャットセッション

- **Claude でのマルチチャットサポート**: 1つのエージェントセッションで複数の関連チャットを保持可能。
- **ピアチャットへのフォーク**: 会話の任意のポイントから別アプローチを探索。
- **チャットの閉じる・再開・削除**: タブメニューからの管理。
- **キーボードドリブンなナビゲーション**: エージェントウィンドウ内でのショートカット操作。

### チャットとモデルのアップデート

- **Copilot Vision GA**: 画像やPDFをチャットに追加可能に。
- **AI クレジット使用量の確認**: Business/Enterprise ユーザーが現在の課金サイクルの使用量を確認可能。
- **エージェントウィンドウでの BYOK モデル利用**: BYOK モデルがエージェントウィンドウでも使用可能に。
- **`!` プレフィックスでのコマンド実行**: チャットメッセージの先頭に `!` を付けてターミナルコマンドを実行。

### エディター・ターミナル・ブラウザ

- **モダン UI プレビュー**: 実験的機能として Stable で利用可能、Insiders ではデフォルト有効。
- **`git diff` からのファイルオープン**: ターミナル diff 出力のファイルパスを選択して直接開く。
- **ブラウザタブ配置の設定**: 統合ブラウザタブの表示位置をカスタマイズ可能。
- **バックグラウンド時のショートカット**: 他のアプリにフォーカスがある状態でも VS Code コマンドを実行可能。
- **プロンプトファイルからスキルへの移行**: 既存のプロンプトファイルを再利用可能なスキルに変換。

### アクセシビリティとディクテーション

- **ビルトインディクテーション**: チャット、エディター、統合ターミナルでのディクテーションが実験的に利用可能。
- **トランスクリプトクリーンアップ**: Copilot による書き起こしのフォーマット整理とフィラーワード除去。
- **ターミナルスクリーンリーダー制御**: 新しい出力到着時にカーソル位置を維持可能。
