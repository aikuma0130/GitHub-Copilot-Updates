# 2026年8月の GitHub Copilot モデル非推奨化予告

## 日付

2026-07-31

## ステータス

Retired (予告)

## 概要

2026年9月1日に複数のモデル（Gemini 3.1 Pro、Claude Opus 4.5/4.6、Claude Sonnet 4.5/4.6、Raptor Mini）が全 Copilot エクスペリエンスで廃止予定。各モデルの代替が案内されている。

## 詳細

以下のモデルが 2026年9月1日に全 GitHub Copilot エクスペリエンス（Copilot Chat、インライン編集、Ask/Agent モード、コード補完）で非推奨化される。

| モデル | 廃止日 | 推奨代替 |
|--------|--------|----------|
| Gemini 3.1 Pro | 2026-09-01 | Gemini 3.6 Flash |
| Claude Opus 4.5 | 2026-09-01 | Claude Opus 4.7 / 4.8 / 5 |
| Claude Opus 4.6 | 2026-09-01 | Claude Opus 4.7 / 4.8 / 5 |
| Claude Sonnet 4.5 | 2026-09-01 | Claude Sonnet 5 |
| Claude Sonnet 4.6* | 2026-09-01 | Claude Sonnet 5 |
| Raptor Mini | 2026-09-01 | MAI-Code-1-Flash |

※ Claude Sonnet 4.6 は年間プランの個人 Copilot 利用者には引き続き提供される。

### 管理者向けの対応

Copilot Enterprise 管理者は、代替モデルへのアクセスを Copilot 設定のモデルポリシーから有効化する必要がある場合がある。非推奨化されたモデルの削除に特別な操作は不要。
