# Copilot Cloud Agent の推論レベルカスタマイズ

## 日付

2026-08-03

## ステータス

GA

## 概要

Copilot Cloud Agent にタスクを委任する際、モデルの推論レベルを設定できるようになった。推論レベルを高くすると複雑な問題に対する回答品質が向上するが、より多くのトークン（クレジット）を消費する。

## 詳細

タスク開始時にモデルと併せて推論レベルを選択すると、Copilot Cloud Agent がその設定で実行される。この機能は Copilot Cloud Agent を含むすべての有料プラン（Copilot Pro、Pro+、Business、Enterprise、Max）で利用可能。
