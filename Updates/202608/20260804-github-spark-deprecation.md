# GitHub Spark の github.com での廃止予告

## 日付

2026-08-04

## ステータス

Retired

## 概要

GitHub Spark は新規ユーザー受付とアプリ作成を停止。既存ユーザーは2026年8月31日までにアプリをエクスポート可能。デプロイ済みアプリは引き続き動作する。

## 詳細

2026年8月4日より、GitHub Spark は新規ユーザーの受付および新規アプリの作成を停止した。AI モデルとエージェント型開発ツールの進歩により、VS Code、Copilot CLI、GitHub Copilot アプリなど既存の開発環境でアプリケーション構築が可能になったことが背景。

### 利用者への影響

- デプロイ済みアプリは GitHub Spark 終了後も引き続き動作する
- 2026年8月31日までに Spark ワークベンチからリポジトリを作成してアプリコードをエクスポート可能
- `llm()` を使用しているアプリは、GitHub Models が2026年7月30日に廃止されたため、独自の推論プロバイダーへの置き換えが必要
