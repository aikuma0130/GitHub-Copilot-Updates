# Copilot Billing Preview アプリの廃止

## 日付

2026-08-04

## ステータス

Retired

## 概要

GitHub Copilot Billing Preview アプリが廃止された。Copilot の利用状況と課金管理は GitHub の課金設定ページから直接確認可能。

## 詳細

使用量ベースの課金への移行に伴い、請求内容の理解を支援していた Copilot Billing Preview アプリが廃止された。現在は課金設定ページがより包括的なビューを提供しており、ユーザーレベルの予算、コストセンター、使用量プール配分などアプリでは表示できなかった情報も確認可能。

### 代替手段

- **AI usage ページ**: 課金設定の AI usage ページで AI クレジットデータをグループ化、フィルタリング、エクスポート可能
- **予算設定**: 支出上限を設定して管理可能
- **ユーザーレベルの予算**: 組織/エンタープライズで個人レベルの支出を制御・追跡可能
- **使用量レポートと API**: 生の使用量データをいつでも取得可能
