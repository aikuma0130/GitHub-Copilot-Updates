# Kimi K3 が GitHub Copilot で利用可能に

## 日付

2026-08-06

## ステータス

GA（ロールアウト一時停止中）

## 概要

オープンウェイトのフロンティアレベル AI モデル「Kimi K3」が GitHub Copilot で利用可能に。エージェントコーディングに最適化され、高いコスト効率を実現。

## 詳細

Kimi K3 は Fireworks AI 上でホストされるオープンウェイトモデルで、エージェントコーディングにおいてフロンティアレベルの性能を発揮します。

### 料金

- 入力トークン: $3 / 100万トークン
- 出力トークン: $15 / 100万トークン
- キャッシュ入力トークン: $0.30 / 100万トークン

### 対応環境

- Visual Studio Code
- Visual Studio
- Copilot CLI
- GitHub Copilot Cloud Agent
- Copilot App
- GitHub.com
- GitHub Mobile（iOS / Android）
- JetBrains
- Xcode
- Eclipse

### 対応プラン

- Copilot Pro / Pro+ / Max
- Copilot Business（管理者による有効化が必要）
- Copilot Enterprise（管理者による有効化が必要）

### 注意事項

- GitHub Actions に関するインシデントの影響により、ロールアウトが一時停止中。問題解決後に再開予定。
- Business / Enterprise プランではデフォルト無効。管理者がセキュリティ・コンプライアンス要件を考慮した上で有効化する必要あり。
