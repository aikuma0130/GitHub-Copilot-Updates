# Visual Studio Code v1.131.0 (July 2026) — GitHub Copilot 関連アップデート

## リリース日

2026-07-29

## VS Code バージョン

1.131.0

## 概要

エージェントホストの継続的な改善、サブエージェントの実行状況の可視化強化、ディクテーション機能の組み込みによる Copilot 連携、Agents ウィンドウでのハイブリッド Markdown エディターの導入など、エージェント体験をさらに進化させるリリース。

---

## GitHub Copilot 関連の変更点

### エージェントホストの継続的改善

前回のリリースに引き続き、エージェントホストの開発が継続されています。エージェントホストは [Agent Host Protocol](https://microsoft.github.io/agent-host-protocol/)（AHP）に基づく専用プロセスで、Copilot、Claude、Codex などのエージェントハーネスを実行します。セッションが独自のプロセスで動作するため、同じセッションを複数の VS Code ウィンドウから同時に接続・表示できます。

エージェントホストの Copilot エージェントは引き続き [Copilot SDK](https://www.npmjs.com/package/@github/copilot-sdk) を使用しており、Copilot CLI、スタンドアロン GitHub Copilot アプリ、その他の Copilot 製品と動作・機能が統一されています。

オプトインするには `chat.agentHost.enabled` を有効にし、ハーネスドロップダウンからエージェントホストハーネスを選択します。この設定は組織レベルで管理されるため、変更するには管理者に連絡する必要があります。

---

### サブエージェントの実行情報の可視化強化（Agents ウィンドウ）

複雑なタスクを処理する際、エージェントは[サブエージェント](https://code.visualstudio.com/docs/agents/concepts/agents#_subagents)にタスクを委任し、独自のコンテキストウィンドウで並列実行できます。今回のリリースでは、サブエージェントの会話を開かなくても、実行中のサブエージェントの状況をすばやく確認できるようになりました。

Agents ウィンドウのメイン会話で、実行中の各サブエージェントについて以下の情報が表示されます：

- サブエージェントが使用しているモデル
- サブエージェントの実行時間
- サブエージェントがアクティブに呼び出しているツール

実行中のサブエージェントを選択すると、別のチャットでその会話が開き、親会話を利用可能な状態に保ちながら進行状況を詳細に確認できます。

### 組み込みディクテーション機能と Copilot 連携（実験的）

**設定**: `dictation.enabled`、`dictation.showTranscript`、`dictation.experimental.llmCleanup`

VS Code でディクテーション（音声入力）を使用するために、VS Code Speech 拡張機能のインストールが不要になりました。組み込みの音声認識サービスがチャット入力、テキストエディター、統合ターミナルで動作し、各サーフェスに適したライブテキストとコントロールを提供します。

組み込みディクテーションはプライベートでオフラインの Nemotron モデルを使用し、音声はデバイス上に保持されます。

`dictation.experimental.llmCleanup` を有効にすると、Copilot が音声入力中のトランスクリプトをリアルタイムで整形し、フォーマットの追加やフィラーワードの除去を行います。トランスクリプトのテキストは言語モデルに送信されてクリーンアップされます。クリーンアップが利用できない場合は、未加工のトランスクリプトがそのまま使用されます。

#### 対応プラットフォーム

- Windows x64 および Arm64
- macOS（Apple Silicon）
- Linux x64 および Arm64（glibc 2.34 以降）
- リモートワークスペース（音声認識はローカルの VS Code クライアントで実行）

#### 未対応プラットフォーム

- VS Code for the Web
- Intel ベースの Mac、32 ビットシステム、Arm32 システム

---

### ハイブリッド Markdown エディター（実験的）

**設定**: `workbench.editor.markdownDefaultEditorInAgentsWindow`

Agents ウィンドウに新しいハイブリッド Markdown エディターが導入されました。Markdown ファイルの表示、インプレース編集、およびエージェントが処理できるコメントの追加が可能です。

**Reopen Editor With** を使用して、テキストエディターとこの新しい Markdown エディターを切り替えることができます。Agents ウィンドウとエディターウィンドウの両方で利用可能です。
