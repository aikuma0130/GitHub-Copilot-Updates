# Visual Studio Code v1.132.0 (August 2026) — GitHub Copilot 関連アップデート

## リリース日

2026-08-05

## VS Code バージョン

1.132.0

## 概要

エージェントホストの段階的ロールアウト、サイドチャット（`/btw`）の導入、チャットでのターミナル出力リフロー、ディクテーションの多言語対応強化、ハイブリッド Markdown エディターでの差分表示など、エージェント体験と音声入力を大幅に改善するリリース。

---

## GitHub Copilot 関連の変更点

### エージェントホストの段階的ロールアウト

エージェントホストが段階的に全ユーザーへのロールアウトを進めています。エージェントホストは [Agent Host Protocol](https://microsoft.github.io/agent-host-protocol/)（AHP）に基づく専用プロセスで、Copilot、Claude、Codex などのエージェントハーネスを実行します。同じエージェントセッションに複数の VS Code ウィンドウから接続できます。

エージェントホストの Copilot エージェントは [Copilot SDK](https://www.npmjs.com/package/@github/copilot-sdk) を使用しており、Copilot CLI、スタンドアロン GitHub Copilot アプリ、その他の Copilot 製品と動作・機能が統一されています。

エディターウィンドウでハーネスドロップダウンから `Copilot` ハーネスを選択できます。

---

### サイドチャット（`/btw`）

現在のターンを中断せずに質問したい場合、チャット入力に `/btw` と入力してサイドチャットを開くことができます。サイドチャットはプライマリチャットのコンテキストとプロンプトキャッシュを共有するため、現在のターンに関する質問が可能です。

また、チャット応答内のテキストを選択して、その応答に関する文脈的な質問を行うこともできます。`#chat:` と入力してチャットタイトルを選ぶか、チャットタブを入力ボックスにドラッグすることで、他のチャットのコンテキストを参照・共有できます。

---

### セッションアクティビティのステータスピル（Agents ウィンドウ）

エージェントがファイル、サブエージェント、プレビュー、ブラウザをまたいで作業する際、チャット入力の上にライブステータスピルが表示され、進行状況の追跡と関連作業への素早いアクセスが可能になりました。

- **Changes** — 変更数の要約を表示。選択するとリアルタイムで更新されるマルチファイル差分が表示されます。
- **Previews** — エージェントが作成・編集した Markdown ファイルのプレビューにアクセスできます。
- **Subagents** — サブエージェントの作業を別のチャットで開いて確認できます。
- **Browsers** — エージェントが統合ブラウザを操作している様子を追跡できます。

---

### エディタータイプの切り替え（Agents ウィンドウ）

**設定**: `breadcrumbs.showEditorType`

複数のエディタータイプが利用可能な場合、Agents ウィンドウにエディタータイプドロップダウンが表示され、通常エディターと差分エディターを切り替えることができます。**Reopen Editor With** コマンドを使用する必要がなくなりました。ドロップダウンはブレッドクラムバーの右側に配置され、ファイルナビゲーション機能も提供します。

エディターウィンドウでもこのドロップダウンを表示するには、`breadcrumbs.showEditorType` を有効にします。

---

### チャットでのターミナル出力リフロー

チャット内の展開されたターミナル出力が、ビューのリサイズに合わせて利用可能な幅にリフローされるようになりました。以前は固定幅で表示されていたため、行が早期に折り返されたり、広いビューで未使用のスペースが残っていました。

この改善は、ローカルエージェントハーネスおよびエージェントホスト上の Copilot ハーネスの両方のターミナル出力に適用されます。

---

### ディクテーションのオンボーディングと多言語対応の強化

**設定**: `agents.voice.language`

ディクテーション（音声入力）を初めて使用する際のオンボーディング体験が追加されました。マイクの確認、ライブ波形表示、複数マイクがある場合のデバイス選択、設定やカスタマイズへのリンクが提供されます。**Voice Mode: Show Introduction** コマンドで再表示できます。

デフォルトのオンデバイスモデルが多言語対応の Nemotron 3.5 に変更され、音声はデバイス上に保持されたまま `agents.voice.language` 設定に従います。自動言語選択では、サポートされている場合はシステムまたはブラウザのロケールが使用され、それ以外ではモデルが言語を検出します。

**Voice: Configure Dictation Instructions** を実行すると、プロジェクトの用語やフォーマット設定に合わせてトランスクリプトを調整できます。`~/.copilot/dictation.md` と信頼されたワークスペースの `.github/dictation.md` の指示が組み合わされます。

---

### ターミナルのシェル対応ディクテーション

ターミナルでのディクテーションがシェル構文を認識するようになりました。例えば「git commit dash m hello world」と発話すると、文字通りの単語ではなく `git commit -m "Hello World"` が生成されます。

---

### ハイブリッド Markdown エディターでの差分表示（実験的）

前回のリリースで導入されたハイブリッド Markdown エディターで、Markdown 差分を表示できるようになりました。変更されたドキュメントは編集可能なまま、ガターインジケーターで追加・変更・削除されたコンテンツがハイライトされます。エディタータイプドロップダウンを使用して、テキスト差分と差分注釈付き Markdown エディターを切り替えることができます。

---

### 統合ブラウザでの要素レベルフィードバック

統合ブラウザで Web ページの特定の要素を選択し、エージェントフィードバックとして注釈を付ける機能が追加されました。キーボードショートカットでこのモードをトリガーし、複数の要素を選択してそれぞれにコメントを追加してからチャットに送信できます。

---

### `ChatAgentHostEnabled` ポリシーの削除

`ChatAgentHostEnabled` ポリシーが削除されました。管理者はポリシーを通じてエージェントホストを一元的に無効化できなくなりました。開発者は引き続き `chat.agentHost.enabled` 設定を使用して、エージェントを別のエージェントホストプロセスで実行するかどうかを選択できます。
